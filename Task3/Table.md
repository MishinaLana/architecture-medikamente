# Классификация данных и инструменты защиты

## Категория 1: Персональные данные (PII)

| Данные | Необходимость защиты | Инструменты защиты |
|--------|---------------------|-------------------|
| **ФИО пациента** | Требование 152-ФЗ ст. 7, риск идентификации личности, защита от социальной инженерии | AES-256-GCM шифрование в БД, токенизация с сохранением формата, динамическое маскирование (xx xxx), RBAC с минимальными привилегиями |
| **Паспортные данные** | 152-ФЗ ст. 10, высокий риск мошенничества, кражи личности, требования банковских систем | Формат-сохраняющее шифрование (FPE), vaultless tokenization, строгий аудит доступа, HSM для ключей шифрования |
| **Контактные телефоны** | Защита от спама, фишинговых атак, несанкционированных рассылок | Частичное маскирование, шифрование в БД, ограничение экспорта, DLP мониторинг |
| **Адреса проживания** | Физическая безопасность пациентов, защита от преследования, 152-ФЗ ст. 11 | Географическое обобщение (только город/район), шифрование полных адресов, доступ только по минимальной необходимости |
| **Дата рождения** | Возрастная идентификация, демографические атаки, построение поведенческих профилей | Обобщение до возрастных групп (20-30 лет), шифрование точной даты, ограничение в отчетности |
| **Email адреса** | Защита от спама, фишинга, корпоративных атак | Токенизация доменной части, шифрование локальной части, верификация отправителей |

## Категория 2: Медицинские данные (PHI)

| Данные | Необходимость защиты | Инструменты защиты |
|--------|---------------------|-------------------|
| **Диагнозы и истории болезней** | Врачебная тайна (323-ФЗ ст. 13), репутационные риски, дискриминация | AES-256-GCM, ABAC на основе роли врача, временные ограничения доступа, журналирование |
| **Результаты лабораторных анализов** | Конфиденциальность здоровья, страховые риски, профессиональные ограничения | Шифрование + контроль доступа по ролям, автоматическое обезличивание для исследований, сроки хранения |
| **Назначения лечения** | Профессиональная ответственность, качество услуг, юридические риски | Цифровая подпись назначений, версионность изменений, RBAC с временными ограничениями |
| **Медицинские изображения (рентген, МРТ)** | Большой объем, сложность анонимизации, диагностическая ценность | Шифрование DICOM, водяные знаки с идентификаторо|
| **Генетические данные** | Высокий риск дискриминации, семейные последствия, этические нормы | Дополнительное шифрование, запрет на экспорт, особые политики хранения |

## Категория 3: Финансовые данные

| Данные | Необходимость защиты | Инструменты защиты |
|--------|---------------------|-------------------|
| **Реквизиты банковских карт** | PCI DSS, финансовое мошенничество, требования ЦБ РФ | Tokenization, vaultless encryption, изоляция в отдельном сегменте сети, регулярный аудит |
| **Суммы платежей и операций** | Коммерческая тайна, конкурентные риски, налоговая отчетность | FPE, агрегация в отчетах, маскирование для рядовых сотрудников |
| **Фискальные данные и чеки** | 54-ФЗ, налоговая отчетность, юридическая сила документов | Криптографическая подпись ФН, защищенное хранение чеков, верификация подлинности |
| **Договоры и финансовые документы** | Юридическая сила документов, судебные споры, аудиторские проверки | Электронная подпись, WORM-хранилище, контроль версий |

## Категория 4: Операционные и системные данные

| Данные | Необходимость защиты | Инструменты защиты |
|--------|---------------------|-------------------|
| **Журналы записей к врачам** | Расписание работы, нагрузка специалистов, коммерческая информация | RBAC, детальное логирование доступа, маскирование пациентов в общих отчетах |
| **Учетные данные сотрудников** | Авторизация в системе, доступ к конфиденциальным данным, внутренние угрозы | Hash + salt (bcrypt), многофакторная аутентификация, сессионные токены, регулярная ротация |
| **Системные логи и аудит** | Расследование инцидентов, судебные запросы, compliance отчетность | SIEM интеграция, криптографическое хеширование логов, ретеншн политики |
| **Конфигурационные данные** | Безопасность системы, предотвращение атак на инфраструктуру | Шифрование секретов, разделение доступа, версионность конфигов, backup шифрование |

## Категория 5: Аналитические данные

| Данные | Необходимость защиты | Инструменты защиты |
|--------|---------------------|-------------------|
| **Агрегированная статистика** | Бизнес-аналитика, научные исследования, отчетность перед регуляторами | k-анонимность (k≥5), l-разнообразие, t-близость, дифференциальная приватность |
| **Метаданные процессов** | Оптимизация работы, планирование ресурсов, улучшение сервиса | Обобщение временных меток, удаление идентификаторов, агрегация по группам |
| **Тренировочные данные ML** | Обучение моделей, научные исследования, улучшение диагностики | Полная анонимизация, синтетические данные, дифференциальная приватность |
